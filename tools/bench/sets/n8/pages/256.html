Uploading files in chunks

Large files are sent in parts of 8 MB. Each part is retried up to three times before the upload fails.

Call finishUpload() after the last part; the server then joins the parts in order.

upload.part(file, { size: 8 * 1024 * 1024 })

Documentation version

Older versions are kept for reference and get no fixes.
