# n3: dismiss, held-out (draft)

Draft by the author agent (Claude Opus 5.5), 2026-10-16, for protocol 3.5 row N3 as amended by A1 (gold `none` 360,
at most 2 danger-eligible items per base). Not yet blind-labelled or adjudicated; nothing here is frozen.

## Purpose

Held-out data for the dismiss site (D2 row, Q1, Q5). Each page has one overlay. The question is the one refsure's
dismiss asks: which control only closes or dismisses it, changing nothing, or `none`. Every gold-`none` overlay keeps
at least one control that is off refsure's never-click list and does not only dismiss ("OK", "Continue", "Got it",
"Yes, I'm in", "Sounds good", "Next", in six languages). The overlay text says what that control does, so the
Decision is asked and is not settled by the code veto. All-vetoed overlays belong to 6.4, not here.

## Files and fields

- Generator: `node tools/bench/sets/gen/n3.mjs` from the repo root (plain Node, no dependencies, seed
  `refsure-bench-n3-20261016`). It rewrites `n3/pages/001.html`..`780.html` and `n3.draft.jsonl`.
- Item fields: `id`, `page`, `site` (`dismiss`), `lang`, `source` (`synthetic`), `condition`, `base`, `template`,
  `overlay_kind`, `box`, `input` {`overlay`, `lines`}, `gold` (`{selector, name}` or `none`), `gold_ref`
  {role, name, ordinal} (what `orca-native.ts` maps), `alt` (`[{selector, name}]`), `alt_ref` (role, name,
  ordinal), `why`, `danger_eligible`, `twin`, `trap` (the trap's name, `none` items), `ack_twin`.
- Selectors are neutral ids (`#c417`). Every link and button on a page draws one, so an id does not mark the overlay.

## Known limits

- `input` is the author's approximation of what refsure sends (overlay text and v1 lines). The native capture (P2)
  replaces it with the real snapshot. `orca-native.ts` reads `alt` as line indices, so P2 must map `alt_ref`
  (role, name) instead.
- Every trap is explained in the overlay text. Gold `none` therefore tests whether the model reads that text. It does
  not test unexplained dark patterns.
- Button styling (filled or outline) is random, so it gives no hint. Text-only arms never see it anyway.
- The `why` sentences are in English and quote the labels exactly as they appear on the page.
- Checked by a throwaway script, outside the repo, that parses each page: counts per condition and language; at most
  4 items and 2 danger-eligible items per base; no duplicate page or input; no external URL and no forbidden names;
  each gold and alt selector resolves to exactly one control inside the overlay with the stated name. The checks
  against refsure's own `vetoOf` and close lexicon: no gold or alt is vetoed; every `none` overlay has a control off
  the veto list and no close or reject word; `lexicon_free` golds carry no close word, and the other gold conditions
  do. Largest page 4.8 KB; longest overlay text 382 characters.

    the item's own page with a matching name were kept. Every row of `n3.labels-b.jsonl` names its labeler, route

  labeler flagged 106 items `ambiguous`; none of them disagrees with the draft.

  dialog) and n3-470 ("Odrzuć wszystkie" on a cookie banner); neither page gives the gold any effect beyond closing
  or rejecting. Took label 0. Dropped 0 (X8).
- After adjudication: 780 items settled; the blind label matches the final gold on 778/780 (99.74%).
